# ArTechulate - Official Landing Page

Interactive speech therapy and articulation practice platform for children ages 3–12.

Official Website: [artechulate.io](https://artechulate.io)

---

## 🚀 Features

- **Gamified Articulation & Speech Therapy**: Engaging speech games with child-friendly themes.
- **Hardware Integration**: Dedicated IoT articulation controller with 3.5mm wired headset & in-line mic.
- **Dual Support Ecosystem**: Coordinated tools for speech-language pathologists and parents.
- **Fully Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewing.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## 🌐 Deploy to Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Assign your custom domain: `artechulate.io`
